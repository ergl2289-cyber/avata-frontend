# Деплой фронтенда (для разработчика)

Фронтенд собирается **на сервере** из исходников. `dist/` в гите нет.

## Как обновить фронт на сервере

```bash
# 1. Зайти на сервер
ssh root@avata.site

# 2. Перейти в папку фронта
cd /home/avata-frontend

# 3. Подтянуть изменения из гита
git pull origin main

# 4. Установить зависимости (если в package.json что-то поменялось)
npm install

# 5. Собрать продакшен-билд
npm run build

# 6. Всё. nginx раздаёт статику из dist/
```

После `npm run build` обновлённые файлы `dist/` сразу подхватываются nginx. Никаких рестартов не нужно.

## Что важно помнить

- `dist/` в `.gitignore` — не пушится, не пулитьcя
- `npm install` только если изменился `package.json` или `package-lock.json`
- Если новый пакет в `package.json` — `npm install` обязателен
- После билда проверить: открыть `https://avata.site` в браузере
