# Avata — project conventions (always-loaded context)

Telegram Mini App «Avata» — доска объявлений по продаже авто (аналог Авито внутри Telegram).
Фронтенд: Vue 3 + TS + Vite + Tailwind + Pinia + Vue Router + @twa-dev/sdk + lucide-vue-next.
Бэкенд: Directus + FastAPI — **готов, работает через api.avata.site**. Авторизация: Telegram initData (Mini App) + OAuth Widget (браузер).

Эти правила обязательны и должны соблюдаться во всех новых экранах/компонентах.

## Bottom sheets — ЕДИНЫЙ ПАТТЕРН (важно)
- **Все шторки в приложении делаем через один компонент:** `src/components/ui/BottomSheet.vue`.
  Нельзя писать отдельную/самодельную шторку под каждый экран — переиспользуем этот.
- **Эталон использования:** `src/components/car/FilterSheet.vue` (шторка фильтров). Любая новая
  шторка (выбор города, сортировка, действия по объявлению и т.д.) строится по её образцу:
  заголовок через `title`, контент в слоте по умолчанию, основная кнопка действия в слоте `#footer`.
- **Поведение шторки (уже реализовано, не ломать):**
  - выезжает снизу, плавно (300ms, ease `cubic-bezier(0.16,1,0.3,1)`), уезжает свайпом/закрытием;
  - закрывается свайпом вниз по любой части шторки + тапом по затемнению (backdrop);
  - drag-to-dismiss с **прогрессивным сопротивлением**: в начале туже (нужно больше усилия),
    дальше ближе к 1:1 (ручки `DRAG_BASE`, `DRAG_EASE`, порог `CLOSE_THRESHOLD`);
  - умный guard: пока внутренний контент проскроллен — свайп скроллит контент, а закрывает
    только когда список вверху;
  - haptic при закрытии. Никаких резких/мгновенных закрытий.

## Дизайн-принципы (строго на всех экранах)
- Ориентир — Авито: крупные фото, цена акцентом, чистые карточки, лаконичная типографика.
- **Никаких эмодзи.** Только минималистичные line-иконки (`lucide-vue-next`).
- Единый стиль везде из дизайн-токенов Tailwind (`tailwind.config.ts`): цвета (`bg`, `surface`,
  `surface-2`, `text`/`text-muted`/`text-faint`, `like`), радиусы (`card`/`sheet`/`pill`),
  тайминги (`fast`/`base`/`slow`), ease `out-ios`. Не хардкодить новые цвета/радиусы мимо токенов.
- Тема **только тёмная монохромная** (как референс). Не зависим от Telegram `colorScheme`.
- Плавность как в iOS: переходы 200–300ms ease-out, smooth scroll.
- Тактильная отдача (`HapticFeedback` через `useTelegram()`) на тапах по кнопкам/карточкам/лайкам.
- У интерактивных элементов состояние pressed (лёгкое сжатие/затемнение, `active:scale-*`).

## Авторизация
- Telegram Mini App: `WebApp.initData` → `POST /api/auth/telegram` → JWT (HMAC-валидация на бэке)
- Браузер: `LoginView.vue` → OAuth-редирект → `POST /api/auth/widget` → JWT (HMAC-SHA256)
- После обновления страницы: `tgStore.user` восстанавливается из `GET /api/users/me`

## Данные и архитектура
- **Все данные — через слой `src/api/` (сервисы).** Компоненты не знают, откуда данные.
- **Единая точка подмены mock → бэкенд:** флаг `VITE_USE_MOCKS=false`. Справочники (`catalog.service.ts`, `geo.service.ts`) при реальном режиме ходят через FastAPI `/api/references/*` и `/api/geo/*`.
- **Моки точно повторяют формат Directus:** обёртка `{ data: [...] }` / `{ data: {...} }` — не упрощать форму.
- Два типа машины: лёгкий `CarListItem` (лента) + полный `CarDetail` (карточка). `feedItemToList()` проекцирует бэкенд → формат фронта.
- `CarListItem` содержит `views_global`/`likes_global` — реальные цифры из БД.
- Отзывы: `ReviewItem` включает `photos?: PhotoInfo[]`. Загрузка фото через `POST /api/reviews/{id}/photos`.
- Название машины = `model.brand.name + model.name`.

## Безопасность
- **Токен бота и любые секреты — не часть фронтенда.** Никогда не просить токен, не вставлять в код.
  Если токен попал в чат — напомнить отозвать. Все ключи только в `.env` (в `.gitignore`).
- Авторизация только через Telegram `initData` (telegram_id, username, first_name). Валидация
  подписи — на бэкенде. Экрана согласия в приложении нет.

## Dev / тест в Telegram
- Vite строго: `port 5173`, `strictPort: true`, `allowedHosts: ['dev.avata.site']`, `host: true`
  (IPv4+IPv6 — иначе SSH-туннель на Windows даёт 502).
- Туннель (поднимает пользователь сам, не часть кода): `ssh -R 5173:127.0.0.1:5173 root@avata.site`.
  При «хочу проверить в Telegram» — напоминать: 1) запущен ли `npm run dev` на 5173, 2) поднят ли туннель.

## Процесс
- Идём экран за экраном по референсам (скриншоты из Авито). Главная (`HomeView`) — готовый образец.
- Перед крупной задачей пользователь включает plan mode. Использовать нужные skills
  (frontend-design для вёрстки, TDD точечно для логики), но не перегружать.
- Тесты — только логика (Vitest): api/mock-слой, утилиты. UI без тяжёлых тестов.
